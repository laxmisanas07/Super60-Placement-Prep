## 💻 Getting Started

### 1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

### 2. Clone the Repository

```bash
git clone https://github.com/laxmisanas07/Super60-Placement-Prep.git
```

### 3. Navigate to the Python Folder

```bash
cd Super60-Placement-Prep/Python
```

### 4. Run a Python Program

```bash
python 1stday.py
```

Alternatively:

```bash
python3 1stday.py
```
